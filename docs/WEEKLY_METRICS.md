# Haftalık ölçüm (Faz C6) — her pazartesi 5 dk

Kurucu her hafta aşağıdaki satırı doldurup sohbete yapıştırır; Claude tabloya ekler ve yorumlar.

```
Hafta: YYYY-MM-DD
Pinterest gosterim: 
Pinterest kaydetme: 
Pinterest outbound click: 
Etsy ziyaret (toplam / Pinterest'ten): 
Etsy favori: 
Etsy satis (adet / $): 
En cok tiklanan pin (varsa): 
```
Kaynaklar: Pinterest Analytics (Overview, son 7 gün) · Etsy Shop Manager → Stats → son 7 gün → Traffic sources.

## Karar kuralları
- 2 hafta outbound click < 10 → pin tasarımı/başlık değişir (Hero / Process / Materials hangisi iyiyse ondan çoğalt).
- Pinterest ziyareti var ama favori/satış yok → ilan (fiyat, kapak, açıklama) gözden geçirilir.
- Bir pin tipi diğerlerinin 2 katı tıklama alıyorsa sonraki seriler o tipte üretilir.
